PHOTO FOLDER FOR WATER TANKS & WELDING WORK
========================================================================

Place your husband's completed project photos in this folder!

For example:
- my-tank-1.jpg
- stainless-tank-2.jpg
- welding-work-3.jpg

Then open:
src/data/galleryData.js

And update the image link:
image: "/images/projects/my-tank-1.jpg",
isPlaceholder: false

That's all! The website will immediately showcase the real photos.
